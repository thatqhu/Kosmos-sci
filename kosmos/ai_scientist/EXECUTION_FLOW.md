# SCI AI Scientist 执行流程图

## 总体架构流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                     用户启动 SCIResearchWorkflow                      │
│                                                                       │
│  参数:                                                                 │
│  - research_objective: "优化 SCI 重建"                                │
│  - design_space: {recon_families, uq_schemes, ...}                   │
│  - initial_configs: [种子配置1, 种子配置2, ...]                       │
│  - budget_max: 50                                                    │
│  - optimization_objectives: ['psnr', 'coverage', 'latency']          │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│                         初始化阶段                                    │
│                                                                       │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 1. 创建 SCIStateManager                                       │   │
│  │    - 负责持久化存储                                            │   │
│  │    - 维护 Pareto 前沿                                          │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                       │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 2. 创建 SCIExecutorAgent                                      │   │
│  │    - 负责执行单个实验                                          │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                       │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 3. 创建 Planner (支持 Gemini/Claude)                          │   │
│  │    - 检测 API key: GEMINI_API_KEY? ANTHROPIC_API_KEY?        │   │
│  │    - 初始化 LLM 客户端                                         │   │
│  │    - provider: "openai" or "anthropic" or None               │   │
│  │    - model: "gemini-2.0-flash-exp" or "claude-sonnet-4-5"    │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                       │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 4. 创建 AnalysisAgent (可选 LLM 验证)                          │   │
│  │    - enable_llm_verification: True/False                      │   │
│  │    - 标准 Pareto 分析 + 可选 LLM 生成算法                      │   │
│  └─────────────────────────────────────────────────────────────┘   │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│                    种子实验阶段 (可选)                                 │
│                                                                       │
│  IF initial_configs 提供:                                             │
│                                                                       │
│  FOR each config in initial_configs:                                 │
│    ├─ 创建实验任务                                                    │
│    ├─ executor.execute(task) → 运行实验                              │
│    ├─ 提取 metrics (PSNR, Coverage, Latency)                        │
│    ├─ 提取 artifacts (checkpoint, logs, figures)                    │
│    ├─ 创建 ExperimentRecord                                          │
│    └─ state_manager.save_sci_experiment(cycle=0, experiment)        │
│                                                                       │
│  结果: 初始实验数据库                                                  │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│                       主优化循环                                       │
│                                                                       │
│  FOR cycle in range(1, num_cycles + 1):                              │
│                                                                       │
│    ┌──────────────────────────────────────────────────────────┐    │
│    │ Step 1: 获取上下文                                         │    │
│    │                                                             │    │
│    │  context = state_manager.get_sci_context(cycle, lookback=3)│    │
│    │                                                             │    │
│    │  返回:                                                       │    │
│    │  {                                                          │    │
│    │    'explored_configs': [已运行的配置列表],                  │    │
│    │    'pareto_frontier': [当前 Pareto 最优配置],              │    │
│    │    'trends': [历史趋势分析],                                │    │
│    │    'cycle': 当前周期号                                      │    │
│    │  }                                                          │    │
│    └──────────────────────────────────────────────────────────┘    │
│                             │                                         │
│                             ▼                                         │
│    ┌──────────────────────────────────────────────────────────┐    │
│    │ Step 2: 规划阶段 (Planner)                                 │    │
│    │                                                             │    │
│    │  proposed_configs = _simple_planning(context, num_exps)    │    │
│    │                                                             │    │
│    │  详细流程:                                                   │    │
│    │  ┌────────────────────────────────────────────────────┐  │    │
│    │  │ 2a. 构建 summary                                     │  │    │
│    │  │     - total_experiments: 已完成数量                  │  │    │
│    │  │     - recon_families: {family: count}               │  │    │
│    │  │     - uq_schemes: {scheme: count}                   │  │    │
│    │  │     - frontiers: Pareto 前沿信息                     │  │    │
│    │  │     - constraints: {max_latency, min_coverage}      │  │    │
│    │  └────────────────────────────────────────────────────┘  │    │
│    │            │                                               │    │
│    │            ▼                                               │    │
│    │  ┌────────────────────────────────────────────────────┐  │    │
│    │  │ 2b. planner.planner_step(summary, design_space,    │  │    │
│    │  │                          budget)                    │  │    │
│    │  │                                                      │  │    │
│    │  │  ┌──────────────────────────────────────────────┐ │  │    │
│    │  │  │ 2b1. Planner.summarize_world_model()          │ │  │    │
│    │  │  │      总结当前状态                              │ │  │    │
│    │  │  └──────────────────────────────────────────────┘ │  │    │
│    │  │            │                                        │  │    │
│    │  │            ▼                                        │  │    │
│    │  │  ┌──────────────────────────────────────────────┐ │  │    │
│    │  │  │ 2b2. Planner.identify_underexplored_regions()│ │  │    │
│    │  │  │      识别未充分探索的区域                     │ │  │    │
│    │  │  └──────────────────────────────────────────────┘ │  │    │
│    │  │            │                                        │  │    │
│    │  │            ▼                                        │  │    │
│    │  │  ┌──────────────────────────────────────────────┐ │  │    │
│    │  │  │ 2b3. Planner.build_planner_prompt()          │ │  │    │
│    │  │  │      构建 LLM 提示                            │ │  │    │
│    │  │  └──────────────────────────────────────────────┘ │  │    │
│    │  │            │                                        │  │    │
│    │  │            ▼                                        │  │    │
│    │  │  ┌──────────────────────────────────────────────┐ │  │    │
│    │  │  │ 2b4. planner.llm_generate_configs(prompt)    │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  IF provider == "openai":                    │ │  │    │
│    │  │  │    response = client.chat.completions.create()│ │  │    │
│    │  │  │    → Gemini/ChatGPT API 调用                 │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  ELIF provider == "anthropic":               │ │  │    │
│    │  │  │    message = client.messages.create()        │ │  │    │
│    │  │  │    → Claude API 调用                         │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  ELSE:                                        │ │  │    │
│    │  │  │    → 返回模拟配置 (无 API key)               │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  返回: proposals_raw (JSON 配置列表)         │ │  │    │
│    │  │  └──────────────────────────────────────────────┘ │  │    │
│    │  │            │                                        │  │    │
│    │  │            ▼                                        │  │    │
│    │  │  ┌──────────────────────────────────────────────┐ │  │    │
│    │  │  │ 2b5. 验证 & 投影到设计空间                    │ │  │    │
│    │  │  │      FOR each proposal:                      │ │  │    │
│    │  │  │        - project_to_design_space()           │ │  │    │
│    │  │  │        - is_valid_config()                   │ │  │    │
│    │  │  │      返回: valid_configs                     │ │  │    │
│    │  │  └──────────────────────────────────────────────┘ │  │    │
│    │  └────────────────────────────────────────────────────┘  │    │
│    │                                                             │    │
│    │  返回: List[Configuration]                                 │    │
│    └──────────────────────────────────────────────────────────┘    │
│                             │                                         │
│                             ▼                                         │
│    ┌──────────────────────────────────────────────────────────┐    │
│    │ Step 3: 执行阶段                                           │    │
│    │                                                             │    │
│    │  FOR each config in proposed_configs:                      │    │
│    │                                                             │    │
│    │    ┌────────────────────────────────────────────────┐    │    │
│    │    │ 3a. 创建任务                                     │    │    │
│    │    │     task = {                                    │    │    │
│    │    │       'task_id': i,                             │    │    │
│    │    │       'description': f"{family} + {uq_scheme}", │    │    │
│    │    │       'metadata': {'sci_config': config.dict()} │    │    │
│    │    │     }                                            │    │    │
│    │    └────────────────────────────────────────────────┘    │    │
│    │              │                                             │    │
│    │              ▼                                             │    │
│    │    ┌────────────────────────────────────────────────┐    │    │
│    │    │ 3b. executor.execute(task, cycle, context)     │    │    │
│    │    │                                                  │    │    │
│    │    │     实际执行 SCI 重建实验:                       │    │    │
│    │    │     1. 加载数据集                                │    │    │
│    │    │     2. 初始化重建模型 (config.recon_family)     │    │    │
│    │    │     3. 初始化 UQ 模块 (config.uq_scheme)        │    │    │
│    │    │     4. 训练模型 (config.train_config)           │    │    │
│    │    │     5. 评估性能                                  │    │    │
│    │    │     6. 生成 artifacts                           │    │    │
│    │    │                                                  │    │    │
│    │    │     返回: finding = {                           │    │    │
│    │    │       'finding_id': 'exp_xxx',                  │    │    │
│    │    │       'statistics': {                           │    │    │
│    │    │         'psnr': 35.2,                           │    │    │
│    │    │         'coverage': 0.87,                       │    │    │
│    │    │         'latency': 45.3                         │    │    │
│    │    │       },                                         │    │    │
│    │    │       'metadata': {                             │    │    │
│    │    │         'artifacts': {...}                      │    │    │
│    │    │       }                                          │    │    │
│    │    │     }                                            │    │    │
│    │    └────────────────────────────────────────────────┘    │    │
│    │              │                                             │    │
│    │              ▼                                             │    │
│    │    ┌────────────────────────────────────────────────┐    │    │
│    │    │ 3c. 提取结果                                     │    │    │
│    │    │     metrics = _extract_metrics(finding)         │    │    │
│    │    │     artifacts = _extract_artifacts(finding)     │    │    │
│    │    └────────────────────────────────────────────────┘    │    │
│    │              │                                             │    │
│    │              ▼                                             │    │
│    │    ┌────────────────────────────────────────────────┐    │    │
│    │    │ 3d. 创建记录                                     │    │    │
│    │    │     experiment = ExperimentRecord(              │    │    │
│    │    │       id=finding_id,                            │    │    │
│    │    │       config=config,                            │    │    │
│    │    │       metrics=metrics,                          │    │    │
│    │    │       artifacts=artifacts                       │    │    │
│    │    │     )                                            │    │    │
│    │    └────────────────────────────────────────────────┘    │    │
│    │              │                                             │    │
│    │              ▼                                             │    │
│    │    ┌────────────────────────────────────────────────┐    │    │
│    │    │ 3e. 保存到状态管理器                             │    │    │
│    │    │     state_manager.save_sci_experiment(          │    │    │
│    │    │       cycle, experiment                         │    │    │
│    │    │     )                                            │    │    │
│    │    └────────────────────────────────────────────────┘    │    │
│    │                                                             │    │
│    │  END FOR                                                   │    │
│    │                                                             │    │
│    │  结果: 本周期所有实验已保存                                │    │
│    └──────────────────────────────────────────────────────────┘    │
│                             │                                         │
│                             ▼                                         │
│    ┌──────────────────────────────────────────────────────────┐    │
│    │ Step 4: 分析阶段 (AnalysisAgent)                           │    │
│    │                                                             │    │
│    │  pareto_ids, trends = _analyze_pareto(cycle_experiments)   │    │
│    │                                                             │    │
│    │  详细流程:                                                   │    │
│    │  ┌────────────────────────────────────────────────────┐  │    │
│    │  │ 4a. 构建 WorldModel                                 │  │    │
│    │  │     world_model = WorldModel()                      │  │    │
│    │  │     world_model.experiments = all_experiments       │  │    │
│    │  └────────────────────────────────────────────────────┘  │    │
│    │            │                                               │    │
│    │            ▼                                               │    │
│    │  ┌────────────────────────────────────────────────────┐  │    │
│    │  │ 4b. analysis_agent.analysis_step(world_model)      │  │    │
│    │  │                                                      │  │    │
│    │  │  ┌──────────────────────────────────────────────┐ │  │    │
│    │  │  │ 4b1. 按 stratum 分组                          │ │  │    │
│    │  │  │      stratum = (recon_family, uq_scheme)     │ │  │    │
│    │  │  │      例: ("CIAS-Core", "Conformal")          │ │  │    │
│    │  │  └──────────────────────────────────────────────┘ │  │    │
│    │  │            │                                        │  │    │
│    │  │            ▼                                        │  │    │
│    │  │  ┌──────────────────────────────────────────────┐ │  │    │
│    │  │  │ 4b2. FOR each stratum:                       │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  IF enable_llm_verification:                 │ │  │    │
│    │  │  │    ┌────────────────────────────────────┐   │ │  │    │
│    │  │  │    │ LLM 生成验证算法:                   │   │ │  │    │
│    │  │  │    │                                     │   │ │  │    │
│    │  │  │    │ 1. generate_verification_algorithm()│   │ │  │    │
│    │  │  │    │    → 调用 Gemini/Claude 生成 Python │   │ │  │    │
│    │  │  │    │                                     │   │ │  │    │
│    │  │  │    │ 2. execute_verification_code()     │   │ │  │    │
│    │  │  │    │    → 沙盒环境执行                  │   │ │  │    │
│    │  │  │    │                                     │   │ │  │    │
│    │  │  │    │ 3. 返回 LLM 计算的 Pareto 集       │   │ │  │    │
│    │  │  │    └────────────────────────────────────┘   │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  ELSE:                                        │ │  │    │
│    │  │  │    ┌────────────────────────────────────┐   │ │  │    │
│    │  │  │    │ 标准算法:                           │   │ │  │    │
│    │  │  │    │                                     │   │ │  │    │
│    │  │  │    │ 1. compute_pareto_front()          │   │ │  │    │
│    │  │  │    │    FOR exp1 in experiments:        │   │ │  │    │
│    │  │  │    │      FOR exp2 in experiments:      │   │ │  │    │
│    │  │  │    │        IF exp2 dominates exp1:     │   │ │  │    │
│    │  │  │    │          mark exp1 as dominated    │   │ │  │    │
│    │  │  │    │    返回: 非支配配置集              │   │ │  │    │
│    │  │  │    └────────────────────────────────────┘   │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  2. compute_calibration_stats()              │ │  │    │
│    │  │  │     计算校准误差统计                         │ │  │    │
│    │  │  │                                               │ │  │    │
│    │  │  │  3. summarize_trends()                       │ │  │    │
│    │  │  │     生成趋势总结                             │ │  │    │
│    │  │  └──────────────────────────────────────────────┘ │  │    │
│    │  │                                                      │  │    │
│    │  │  返回: (pareto_set_all, trends_all)                │  │    │
│    │  └────────────────────────────────────────────────────┘  │    │
│    │            │                                               │    │
│    │            ▼                                               │    │
│    │  ┌────────────────────────────────────────────────────┐  │    │
│    │  │ 4c. 更新 Pareto 前沿                                 │  │    │
│    │  │     state_manager.update_pareto_frontier(pareto_ids)│  │    │
│    │  └────────────────────────────────────────────────────┘  │    │
│    │                                                             │    │
│    │  返回: (pareto_ids, trends)                                │    │
│    └──────────────────────────────────────────────────────────┘    │
│                             │                                         │
│                             ▼                                         │
│    ┌──────────────────────────────────────────────────────────┐    │
│    │ Step 5: 保存周期结果                                       │    │
│    │                                                             │    │
│    │  cycle_result = {                                          │    │
│    │    'cycle': cycle,                                         │    │
│    │    'experiments_run': len(proposed_configs),               │    │
│    │    'pareto_size': len(pareto_ids),                         │    │
│    │    'trends': trends                                        │    │
│    │  }                                                          │    │
│    │                                                             │    │
│    │  cycle_results.append(cycle_result)                        │    │
│    │  pareto_history.append({...})                              │    │
│    └──────────────────────────────────────────────────────────┘    │
│                             │                                         │
│                             ▼                                         │
│    ┌──────────────────────────────────────────────────────────┐    │
│    │ Step 6: 预算检查                                           │    │
│    │                                                             │    │
│    │  experiments_conducted += len(proposed_configs)            │    │
│    │                                                             │    │
│    │  IF experiments_conducted >= budget_max:                   │    │
│    │    BREAK  # 退出循环                                       │    │
│    └──────────────────────────────────────────────────────────┘    │
│                                                                       │
│  END FOR (循环继续到下一个 cycle)                                     │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│                       最终化阶段                                       │
│                                                                       │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 1. 计算最终统计                                               │   │
│  │    - total_experiments                                        │   │
│  │    - cycles_completed                                         │   │
│  │    - final_pareto_size                                        │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                       │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 2. 找出最优配置                                               │   │
│  │    best_exp = max(pareto_experiments, key=lambda e: e.psnr)  │   │
│  │    best_configuration = best_exp.config                       │   │
```
